1 Salesforce needed

In Salesforce Setup create an External Client App with OAuth, PKCE enabled, scopes api refresh_token, and callback http://localhost:8765/auth/salesforce/callback. Paste its Consumer Key, then sign in.

⚡ Sign in with Salesforce

2 Google Drive — meeting transcripts needed

In the Google Cloud console create an OAuth client (Desktop app type), enable the Drive API, and paste both values. The login asks for read-only Drive access, nothing else. Optional: a folder ID to confine the transcript search.

G Sign in with Google

3 Web research — Tavily needed

Free key at tavily.com. Saving it turns live web research on. Demo accounts keep their curated findings either way.

4 Claude — the judgment layer needed

API key from console.anthropic.com (needs a small credit balance). Saving it turns live synthesis on. The model is swappable — the validation gate holds every model to the same rules.
